# pi-cursor-subagents

Pi package for Cursor Agent subagents.

It includes:

- the `cursor-subagents` Agent Skill;
- a native Pi extension that registers `cursor_run_once`, live ACP session tools,
  model listing, and cleanup tools.

From GitHub:

```bash
pi install git:github.com/RealSid08/cursor-subagents
```

After npm publication:

```bash
pi install npm:pi-cursor-subagents
```

Requires `cursor-agent` and a logged-in Cursor account:

```bash
cursor-agent login
```
